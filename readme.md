# 로또 자판기
***
## 필수사항
***
- 로또는 하나에 1000원
- 로또 번호는 한 장에 6개
- 로또 숫자는 1~45내 중복 없이 번호 추첨
- 각 회차마다 당첨번호는 랜덤으로 정해야하고, 각 회차의 당첨번호는 그 회차의 모든 로또 구매 완료 이후 결정되어야 한다
    1. 당첨번호는 6개 + 보너스 번호 1개로 이루어짐
- 돈을 입금해서 해당 예산 내에서는 로또는 무제한 구매 가능
    1. 예시) 10만원이 있을때 항상 10만원 어치를 구매하진 않을수도 있음 100장 이내로 몇개든 나눠서 구매 가능
- 당첨금은 다시 입금 내역으로 들어간다.
    1. 1등 21억, 2등 6천만, 3등 150만, 4등 5만, 5등 4천
    2. 1등 당첨번호 6개 일치, 2등 5개 일치 + 보너스 번호 일치, 3등 5개 일치, 4등 4개일치, 5등 3개 일치
- 로또 한장을 뽑는 방법은, 수동, 자동을 지원하며 수동, 자동 동시 구매 가능
    1. 예시) 유저가 한번에 총 20장을 구매할때 3장은 수동으로 입력, 17장은 자동으로 구매 할수 있어야함
- 회차는 시간을 기준으로 진행되거나, 수동으로 개발자가 회차를 진행시킨다
- 각 회차의 결과는 저장되어야하며 프로그램을 껐다 켜면 이력을 자동으로 불러와서 다음 회차를 진행해야함
- 과거 회차를 조회할 수 있는 기능이 있어야 한다.
- Validation을 잘 신경써서 에러처리를 작성한다.
- 매직넘버의 사용을 지양하며 되도록 상수로 정의한다.
- 일급 컬렉션을 안쓰는 코드로 작성해보고, 그걸 일급 컬렉션을 사용하는 코드로 리팩토링 해볼 것
- 한개의 메소드가 20줄이 넘지 않도록 작성해볼 것.
- 로또의 당첨확률을 체감해보고 인생의 덧없음을 느낄 것.

## 선택사항
***

- 로또 한장 번호 뽑는 방식에 반자동도 추가해볼 것(6개의 번호 중, N개는 수동, 6-N개는 자동)
- 로또 한장 번호를 뽑는 방식을 전략패턴으로 각 전략을 갈아낄 수 있는 방식으로 작성해볼 것
- 각 클래스는 명확히 구분되는 1개의 책임만을 가져야 하며 한개의 메소드는 한개의 역할만 수행하도록 작업

## 기능 목록
***

### 메인 로직
- [ ] 구매한 로또의 개수 만큼 로또를 발행한다
- [ ] 사용자가 수동 입력한 번호를 검증한다
- [ ] 발행한 각 로또에 대해 당첨 여부를 확인하고 결과를 합산한다.
- [ ] 당첨 결과에 대해 총 수익액을 출력한다

### 입력 및 출력
- [ ] 시작 시 로또 회차를 출력한다 (`제 n 회차 로또 추첨!!`)
- [ ] 로또 구매 안내를 출력한다 (`몇 장을 구매하시겠습니까? - 보유 금액 : n 원`)
- [ ] 사용자로부터 문자열을 입력받는다
- [ ] 구매한 로또 개수를 출력한다 (`n장을 구매했습니다`)
- [ ] 반자동 안내 문자를 출력한다 (`몇 장을 수동으로 구매하시겠습니까?`)
- [ ] 사용자로부터 문자열을 입력받는다
- [ ] 수동 구매 시, n개의 개수 만큼 당첨번호를 입력받는다. 번호는 쉼표(`,`)로 구분한다
- [ ] 로또 결과 안내 메시지를 출력한다

### 예외처리
- [x] 입력된 구매 개수 문자열이 숫자가 아닌 경우, `IllegalArgumentException`을 발생시킨다
- [ ] 입력된 구입 금액보다 예산이 부족한 경우, `IllegalArgumentException`을 발생시킨다
- [x] 입력된 수동 구매 번호가 1~45의 범위 밖인 경우, `IllegalArgumentException`을 발생시킨다
- [x] 입력된 수동 구매 번호가 6개가 아닌 경우, `IllegalArgumentException`을 발생시킨다
- [x] 입력된 수동 구매 번호가 숫자가 아닌 경우, `IllegalArgumentException`을 발생시킨다
- [ ] 구매한 로또 개수보다 수동 구매 갯수가 많을 경우, `IllegalArgumentException`을 발생시킨다
